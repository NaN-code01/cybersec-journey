# Mengapa Saya Memilih Cyber Security

Sebagai mahasiswa Informatika, saya tertarik pada bagaimana teknologi dapat digunakan untuk membuat sesuatu yang bermanfaat, terutama dalam bentuk software, website, maupun sistem digital lainnya. Saya sendiri memiliki tujuan untuk menjadi seorang developer. Untuk game development, mungkin lebih cocok saya jadikan sebagai hobi, tetapi secara umum saya ingin terus mengembangkan kemampuan dalam membuat berbagai macam aplikasi dan sistem. Walaupun kemampuan development saya saat ini masih cukup dasar, saya melihat bahwa ada satu hal yang tidak boleh dipisahkan dari proses menjadi seorang developer, yaitu **keamanan**.

Dari situlah ketertarikan saya terhadap *cyber security* mulai muncul. Menurut saya, membuat sebuah aplikasi tidak cukup hanya dengan memastikan aplikasinya berjalan sesuai fungsi. Aplikasi tersebut juga harus dapat menjaga data, mencegah penyalahgunaan, dan tetap aman ketika digunakan dalam kondisi yang sebenarnya. Sebagus apa pun sebuah sistem, jika keamanannya diabaikan, sistem tersebut tetap dapat menjadi masalah bagi penggunanya.

Hal ini semakin relevan dengan perkembangan dunia digital saat ini. Penggunaan teknologi, AI, dan berbagai layanan digital terus meningkat, sementara ancaman terhadap sistem dan data juga ikut berkembang. Indonesia pun menghadapi tantangan yang sama karena semakin banyak aktivitas masyarakat dan layanan penting yang bergantung pada teknologi. Menurut saya, karena itu pemahaman *cyber security* tidak hanya penting bagi seorang spesialis keamanan, tetapi juga bagi seorang developer.

Itulah salah satu alasan saya bergabung dengan **TISS (Tirtayasa Information Security Society)**. Saya ingin belajar lebih jauh mengenai cyber security melalui diskusi, pembelajaran, dan tambahan pengalaman. Saya juga ingin melihat hubungan antara development dan security secara lebih dekat, sehingga nantinya saya tidak hanya bisa membuat software yang berfungsi, tetapi juga memahami bagaimana membuatnya dengan lebih aman.
