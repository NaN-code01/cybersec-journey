**Subject: Stored Cross-Site Scripting (XSS) Vulnerability in the Comment Section.** A security vulnerability was discovered in the application's comment section, where user-submitted content is stored and displayed without proper input sanitization. During testing, it was found that the application does not adequately validate HTML and JavaScript input before rendering comments on the page. To reproduce this issue, first, log in using a standard user account, then navigate to a page that allows users to submit comments. Enter a test input containing HTML or JavaScript code into the comment field and submit it. Next, access the page containing the submitted comment using another test account and observe how the application processes the content. If the input is executed by the browser rather than displayed as plain text, the vulnerability is confirmed. This issue could allow malicious scripts to execute within other users' browser sessions, potentially compromising their accounts and exposing sensitive information.
