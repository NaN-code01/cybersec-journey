## 👋 About Me

Halo, saya **Yazidil Afnan Martani**, mahasiswa **Informatika** di **Universitas Sultan Ageng Tirtayasa**.

Saya memiliki ketertarikan pada bidang **Cyber Security**, khususnya dalam memahami bagaimana sistem, jaringan, dan aplikasi dapat diamankan dari berbagai ancaman keamanan. Melalui repository ini, saya mendokumentasikan proses dan perkembangan pembelajaran saya selama mengikuti kegiatan **Tirtayasa Information Security Society (TISS)**.

## 📚 Motivasi Bergabung dengan TISS

Saya bergabung dengan TISS untuk memperluas pemahaman dan pengalaman saya dalam bidang Cyber Security melalui pembelajaran, latihan, serta kegiatan yang berkaitan dengan cyber security.

Saya berharap dapat membangun dasar pengetahuan yang lebih kuat, meningkatkan kemampuan dalam menyelesaikan permasalahan keamanan, serta memperoleh pengalaman yang dapat mendukung perkembangan saya di bidang teknologi terutama dallam **mengembangkan software dan sistem yang aman**.

## 💠 Target Rank

Target rank yang ingin saya capai adalah:

- Rank **🛡️Sentinel** untuk tingkatan dasar/L0, dikarenakan Sentinel itu rank terakhir pada tingkatan tersebut. Meskipun sebetulnya fokus saya lebih tertuju pada rank **🛠️Forge** terutamanya karena rank ini lebih sesuai dengan motivasi saya bergabung ke TISS.
- **🟨Yellow Teaming** untuk tingkatan L1 primary dan mungkin **🟩Green Guild** untuk secondary.
